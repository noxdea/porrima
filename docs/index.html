v0.1.0 · Pure Ruby

Text changes, without opinion attached.

Porrima computes line, word, and three-way diffs. You decide how they look, where they live, and what happens next.

Read the quick start View v0.1.0

The diff is data.

Inspect structured edits, hunks, gutter marks, paired rows, and inline spans. Rendering policy stays in your application.

Compare
Linear-space Myers diff with line and token-level refinement.
Patch
Strict unified patches that apply or revert only against exact text.
Merge
Three-way merge with structured conflicts and optional diff3 markers.

Small core. Clear boundaries.

No file reads, no terminal styling, no runtime dependencies. Porrima does the text work and gets out of the way.

Install from RubyGems

$ gem install porrima
